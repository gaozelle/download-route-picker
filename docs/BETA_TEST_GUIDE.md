# 0.5.3 Beta 测试指南

感谢参与测试。一次完整测试大约需要 5 至 15 分钟。

## 测试前

- 确认 Clash Verge Rev 已启动并能正常联网。
- 准备一个无需登录即可下载的 HTTP/HTTPS 文件链接。
- 不要提交订阅地址、密钥或节点凭据。

## 测试步骤

1. 下载 ZIP，把 App 拖入“应用程序”。
2. 右键 App 并选择“打开”。
3. 完成首次启动环境检查。
4. 如果 App 安装了专用配置，按提示重启 Clash Verge，再重新检查。
5. 选择一个保存文件夹，粘贴链接并开始测速。
6. 观察线路速度是否逐条显示。
7. 下载完成后确认最终线路、平均速度、保存路径和打开文件按钮均正常。
8. 在下载过程中观察浏览器、AI App 或其他联网软件是否受到影响。

## 希望得到的反馈

- Mac 芯片与 macOS 版本
- Clash Verge 和 Mihomo 版本
- 是否开启 TUN 模式
- 是否首次就安装成功
- 是否首次就下载成功
- 节点数量和大致耗时
- 其他联网 App 是否受到影响
- 这个工具是否解决了你原来手动切换节点的问题
